# legacy/

`prototype.html` is de oorspronkelijke, met de hand gemaakte SiteForge-mockup
(531 regels, één bestand). Die is **bewust bewaard**: hij legt de bedoelde
gebruikersflow en de visuele richting van de app vast.

De kleuren uit dit prototype zijn overgenomen in `src/app/globals.css`
(`--bg: #0a0a0f`, `--accent: #7c6fff`, enzovoort), en de flow
"bedrijfsnaam → plaats → branche → genereren → preview" is in de echte
applicatie opnieuw opgebouwd.

Dit bestand draait niet mee in de build en wordt niet gedeployed.
Open het met een browser als je de oorspronkelijke schets wilt zien.
